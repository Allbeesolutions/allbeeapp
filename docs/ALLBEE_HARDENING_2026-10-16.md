# AllBee autonomous hardening — 16 October 2026

## Scope and rules
This report covers the 16-item **NPWWMI / HAOR** hardening batch for the existing AllBee app. The repository baseline was `e878ed8` on `main`. No production database mutations, credential changes, service-worker resets, or production deployments were authorized or performed as part of this batch. The existing policy `.ai/HAO_POLICY.json` declares `allow_auto_deploy: false`. Pre-existing unrelated changes to `AGENTS.md` and `.ai/` are intentionally excluded from the product commit.

## Findings and verified local evidence
- **Chat architecture and resilience (items 1, 3, 4, 11):** the canonical Admin/Client/APN/Team chat surfaces and profile resolution were inspected. Added regressions covering cancellation of stale thread requests on back-navigation, preserving an in-flight failed-send draft across thread changes, and cleanup of queued realtime refresh/channel subscriptions on unmount. Existing tests cover duplicate sends, retry, unread/reactions and profile identity.
- **Visual, interaction, mobile, error states (items 2, 7, 14):** 18/18 repaired-chat browser checks; 33/33 legacy chat browser checks; 504/504 cross-role/route/viewport cases; 492/492 populated/empty/error/dark/reduced-motion APN UX cases. Browser checks use isolated fixtures, not production credentials.
- **Accessibility regression found and fixed (item 7):** the anonymous login role-lookup could not select the visible "APN Partner Login" control by its exact accessible name. Explicit accessible names were added to Employee, Client and APN Partner login choices on both relevant login surfaces. The targeted 4-viewport role-based login verification passes after the fix.
- **Finance integrity (items 9, 10):** the disposable PostgreSQL finance RPC harness passed transactional rollback, retry/idempotency, period locks, role/grants, migration replay and concurrent same-key calls. This does **not** certify the remote production schema or migration.
- **Security/PWA (items 5, 12):** full unit suite, edge-auth test, lockdown E2E, local RPC surface audit and production dependency audit passed. RPC audit examined 167 referenced RPCs including 12 protected internal helpers with zero reported violations. Production dependency audit returned one low-severity advisory, zero moderate/high/critical.
- **Performance and modularity (items 6, 13):** main JS bundle is **521.3 KiB / 525.0 KiB budget** and total JS is **2501.8 KiB / 2560.0 KiB budget**. The main `AllbeeApp.jsx` source is approximately 583 KB. All present budgets pass; targeted route-based code splitting is a separately identified future optimization, not a reason to risk a large unrequested behavioral rewrite inside this hardening patch.
- **Mascot collision and interaction (item 8):** the dedicated browser suite completed **497 checks with zero page errors**, covering responsive placement, navigation, protected controls, animation and account surfaces. All related unit/contract assertions passed.
- **Release evidence and Git isolation (items 15, 16):** full certification passed **71 files / 362 tests**, production build and bundle budgets pass. Full execution logs remain local under `.ai/raw/haor-20261016/`; illustrative UI screenshots and JSON evidence remain under `.ai/chat-repair-evidence/` and `.ai/apn-ux-evidence/`. Git changes are limited to verified product accessibility, regression tests, and test-harness improvements. Product commit and push are governed by project policy; no production deployment is automatic.
